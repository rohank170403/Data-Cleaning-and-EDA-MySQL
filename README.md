
# 📊 Data Cleaning and Exploratory Data Analysis (EDA) Using MySQL

### 🧹 Project Overview

This project demonstrates two key SQL-based processes — **Data Cleaning** and **Exploratory Data Analysis (EDA)** — performed entirely in **MySQL**.  
It focuses on transforming raw, inconsistent data into accurate, structured, and insight-ready information for decision-making.

---

## 🧩 1. Data Cleaning in MySQL

The first phase focuses on preparing raw data for analysis by:
- Handling missing or null values.
- Removing duplicate and inconsistent records.
- Standardizing data formats for consistency.
- Validating and correcting data types.

**Outcome:**  
A clean, reliable dataset ready for analytical exploration and visualization.

---

## 📈 2. Exploratory Data Analysis (EDA) in MySQL

The second phase explores the cleaned dataset to identify trends, relationships, and patterns using:
- Aggregate functions (`SUM`, `AVG`, `COUNT`, `MIN`, `MAX`) for summary statistics.  
- `GROUP BY`, `HAVING`, and `ORDER BY` for data segmentation and ranking.  
- Subqueries and window functions for advanced insights.  
- SQL-driven exploration to support business intelligence.

**Outcome:**  
Meaningful insights derived from structured SQL queries, highlighting trends and data-driven opportunities.

---

## ⚙️ Tools & Technologies

- **MySQL 8.0+**  
- **MySQL Workbench / DBeaver**
